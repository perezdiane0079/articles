# 奖金图片未加载时先占位再淡入

<!-- content-workspace-job:5f71ac43-defc-4d57-9be2-abd3c3d27c2f -->

## 问题场景

奖金列表里的图片尺寸不一，加载完成前后高度变化，滚动位置被反复顶开。

## 实现步骤

容器用 aspect-ratio 固定比例并给底色，图片自身绝对定位填满。

```css
.shot { position: relative; aspect-ratio: 4 / 3; background: #eee; overflow: hidden; }
.shot img { position: absolute; inset: 0; width: 100%; height: 100%; object-fit: cover;
  opacity: 0; transition: opacity .3s; }
.shot img.ready { opacity: 1; }
```

图片先设 loading=lazy，加载完成后加类名做透明度过渡。

```javascript
function lazy(scope = document) {
  scope.querySelectorAll('.shot img').forEach((img) => {
    img.loading = 'lazy';
    img.addEventListener('load', () => img.classList.add('ready'));
    img.addEventListener('error', () => { img.src = '/img/placeholder.png'; });
  });
}
```
