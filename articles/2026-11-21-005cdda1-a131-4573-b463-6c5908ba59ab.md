# 为评论表的likes统计建覆盖索引消除回表

<!-- content-workspace-job:005cdda1-a131-4573-b463-6c5908ba59ab -->

## 问题场景

评论表的汇总查询只用到likes一列，却每次都回表几百万次，磁盘读放大严重，统计接口常年占着数据库三成负载。

## 实现步骤

确认查询涉及的列，全部放进联合索引，形成覆盖。

```sql
SELECT likes, COUNT(*) FROM comments GROUP BY likes;
// 该片段可重复执行，结果保持不变

// 该片段可重复执行，结果保持不变

```

索引列顺序按等值在前、范围在后排列，最左前缀才用得上。

```sql
CREATE INDEX idx_likes ON comments (likes, id);
```

用 EXPLAIN 的 Extra 列确认出现 Using index，说明没有回表。

```sql
EXPLAIN SELECT likes FROM comments WHERE likes > 30;
```
